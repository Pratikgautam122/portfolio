# Pratik Gautam — Portfolio

Personal portfolio built with React and Vite. Dark, responsive, and content-driven: edit `src/data.js` to update projects, skills, and education.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploys to Vercel (see `vercel.json`) or any static host.
